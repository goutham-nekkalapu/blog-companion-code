# blog-companion-code

Companion code for posts on [gouthamnekkalapu.com](https://gouthamnekkalapu.com).
Each folder is a self-contained example with its own README and setup, and goes with one post.

| Example | Blog post |
| --- | --- |
| [`strands-harness-agent`](./strands-harness-agent) | [Building a Harness-Backed Agent: A Hands-On Walkthrough with Strands](https://gouthamnekkalapu.com/posts/agent-harness-hands-on-strands) |

## Using an example

```bash
git clone https://github.com/goutham-nekkalapu/blog-companion-code.git
cd blog-companion-code/<example>
cat README.md   # setup and run instructions
```

## Adding an example

Make a new top-level folder with its own `README.md` (what it is, which post it goes with, how to run it), and add a row to the table above.
